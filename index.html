How to get a key (about 5 minutes, free tier)
  1. Open console.cloud.google.com and create a project (e.g. “Jeepney”).
  2. Billing → link a billing account (a card is required). Google includes free monthly usage for each API. Street View is loaded once each time you open the app and ride.
  3. APIs & Services → Library → enable Maps JavaScript API and Places API (New) (things to do & photos), plus Street View Static API for Photo mode and Map Tiles API for the 3D view.
  4. APIs & Services → Credentials → Create credentials → API key. Copy it here.
  5. Edit the key → Application restrictions: Websites → add https://your-site.example/*
    API restrictions → the APIs above → Save.
  6. Optional safety net: Billing → Budgets & alerts → set a small budget alert.

You opened this file directly from disk. Google's “Websites” restriction can't match local files — open it from a website instead.

Google said no

Google Maps rejected the API key. Usually one of these:

  1. Maps JavaScript API isn't enabled in your project.
  2. Billing isn't linked to the project.
  3. The key's Websites restriction doesn't include
  4. The key was just created — it can take a few minutes to start working.

Details are in your browser's developer console.

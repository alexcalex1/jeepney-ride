Drive a jeepney through real Street View. Find every road to the sea, pick up passengers, collect fares.

1 · Google Maps API key

Your key is saved only in this browser.

How to get a key (about 5 minutes, free tier)
  1. Open console.cloud.google.com and create a project (e.g. “Jeepney”).
  2. Billing → link a billing account (a card is required). Google includes free monthly usage per API, and this game uses one Street View session each time you press Start.
  3. APIs & Services → Library → enable Maps JavaScript API (and Street View Static API if you want Photo mode).
  4. APIs & Services → Credentials → Create credentials → API key. Copy it here.
  5. Edit the key → Application restrictions: Websites → add https://your-site.example/*
    API restrictions → Maps JavaScript API (+ Street View Static API) → Save.
  6. Optional safety net: Billing → Budgets & alerts → set a small budget alert, and/or lower the daily limits in the API's Quotas page.

You opened this file directly from disk. Google's “Websites” restriction can't match local files — upload this file to a website (any HTTPS hosting) and open it from there.

Controls

▲ GAS / ▼ BRAKE change gear (N, 1–4). ■ STOP stops for passengers.
